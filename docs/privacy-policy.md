# Salesforce Perspectives Privacy Statement

Effective date: May 15, 2026

Salesforce Perspectives is a Chrome extension that helps signed-in Salesforce users view Salesforce page context in an organized format.

## Data handling

Salesforce Perspectives does not collect, sell, rent, share, transmit, or store personal data or Salesforce data on any external server.

The extension only displays information that is already accessible to the signed-in Salesforce user in their Salesforce organization. This includes Salesforce context such as record type, profile, role, app name, page layout, Lightning record page, permission sets, record identifiers, and page URL.

## How the extension uses data

The extension reads Salesforce page and metadata information only when the user opens or refreshes the extension panel on a Salesforce page. The information is shown locally in the browser to help organize and summarize what the user can already access in Salesforce.

## Local exports

If the user clicks **Save As**, Salesforce Perspectives generates a Word-compatible document locally in the browser. The exported file is downloaded directly to the user's computer. The extension does not upload, transmit, or retain the exported document.

## Authentication and cookies

Salesforce Perspectives may use the user's existing Salesforce browser session to call Salesforce APIs for the current Salesforce organization. This is used only to retrieve and display Salesforce context in the extension panel. Session cookies are not stored by the extension, sent to the developer, or shared with third parties.

## Third parties

Salesforce Perspectives does not send data to third-party analytics, advertising, tracking, or external processing services.

## Remote code

Salesforce Perspectives does not load or execute remote JavaScript or WebAssembly. All executable extension code is included in the extension package.

## Contact

For privacy questions about Salesforce Perspectives, contact the extension owner through the Chrome Web Store listing or the repository where the extension is distributed.
